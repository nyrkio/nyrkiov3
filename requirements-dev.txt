# Editable sibling checkouts for local development.
#
# Production dependencies live in pyproject.toml (jsonee + benchzoo).
# This file overrides them with live, EDITABLE local source so an edit in
# any repo takes effect immediately — no reinstall. Paths are relative to
# this file (the nyrkiov3 repo root).
#
# Set up the whole dev environment in one shot:
#     uv pip install -e . -r requirements-dev.txt
#
# AuroraBorealis is a JS UI library, not a Python package — serve it in
# dev with:  nyrkio-serve --aurora-dir ../AuroraBorealis/static

# SecantusDB is the embedded MongoDB-wire store (jsonee.MongoStore talks to
# it). Editable from source so dev uses our patched secantus (e.g. the
# checkpoint-wait fix) rather than the PyPI pin jsonee would otherwise drag
# in. Building it compiles a vendored WiredTiger (~30s, one-time).
-e ../SecantusDB
-e ../PureJson
-e ../ExtendedJsonSchema
-e ../JsonEE
-e ../../benchzoo
